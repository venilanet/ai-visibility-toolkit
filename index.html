How to use your prompt panel

  1. Run clean. Use a fresh/incognito session so personalization doesn't skew results.
  2. Score every answer the same way: recommended (the AI suggests you) beats cited (your URL is referenced), which beats mentioned (name-drop only). Absent means you're invisible for that question.
  3. Repeat weekly, judge monthly. AI answers are noisy — the same prompt can cite different sources on different days. Only act on 3+ week patterns.
